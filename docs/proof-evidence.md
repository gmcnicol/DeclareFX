## Workflow and artifact protocol

[Compiler proof workflow](../.github/workflows/proof.yml) runs on **every push
to `implement/declarefx-proof`**, plus manual dispatch. Dispatch the integration
branch for acceptance. Three independent jobs use `ubuntu-latest`,
`macos-latest`, `windows-latest`, with fail-fast disabled. Labels float; exact
OS/kernel/architecture and runner `ImageOS`/`ImageVersion` are recorded at runtime,
not asserted from labels. Node comes from `.nvmrc`; pnpm from `packageManager`.
Actions are commit-pinned, permissions read-only, credentials not persisted.
No dependency cache, host install/launch, package publication or external EEL2
interpreter is involved.

Each fresh hosted checkout runs the six commands above plus a tracked-diff
check. Bash's explicit Actions shell uses `-e -o pipefail`, so logging through
`tee` cannot hide a failing command. `pnpm test` builds and runs **all** compiled
Node tests: the complete supported/invalid compiler fixtures, binding/types/
cycles/text/resources, checked frontend diagnostics, DSP restrictions, exact
numeric/plain-decimal/guard structure, CLI aliases/failure preservation/atomic
readers/help/version, golden/provenance and relocated CLI checks. Independent
arithmetic expectations and emitted-source assertions are not a JSFX VM.
`verify:vendor` separately verifies exact bundle/provenance/notice bytes.

`pnpm evidence` invokes the dependency-free Node script
[`scripts/evidence.mjs`](../scripts/evidence.mjs). It copies explicit compiler
build inputs into **two fresh temporary roots**, each without `node_modules` or
`dist`, freezes installation, cleans/builds, and invokes the real compiled CLI.
It checks lockfile preservation, hashes every dist file with normalized relative
names, compares both manifests and every generated byte to the committed
(reviewed, never auto-updated) golden. Temporary roots are removed. Only
`proof-evidence/reproducibility/` is replaced; workflow gate logs are preserved.
The command installs only locked development dependencies into those temporary
roots; it does not install effects or execute DSP. Reusing pnpm's content store
is not a compiler/runtime cache or a source-build parity claim.

Artifacts, uploaded even after failure when files exist, retained **90 days**:

- `proof-linux`, `proof-darwin`, `proof-win32`: `gates/*.log` for actual
  environment, install/build/check/test/vendor/reproducibility/diff commands;
  `reproducibility/result.json` with status, revision, dirty state, run URL,
  actual tools/OS/image/architecture, each command's exit/signal/log/path;
  `inputs.json` with SHA-256 of source/test/example/vendor and metadata/notices;
  `dist-1.json`/`dist-2.json`, six command logs, `gain-1.jsfx`/`gain-2.jsfx`.
- `matrix-comparison`: actual comparison stdout/errors. The dependent job
  downloads all three named platform artifacts without merging directories.
  [`scripts/compare-evidence.mjs`](../scripts/compare-evidence.mjs) rejects missing
  or failed reports, wrong revisions/tools/platforms, unequal input/dist hashes
  and any full-output mismatch against the checked-out golden. It runs even
  after a failed matrix job unless cancelled; missing evidence fails, not passes.

A job failing before reproduction may have only gate logs; failing before
logging/upload (including tool bootstrap), cancellation or artifact loss may
leave no artifact. Consult the Actions job log and mark those gates failed or
unrun; artifact existence alone is never proof of passed gates. Even a successful
comparison does not override a failed matrix job. **Acceptance requires all three
proof jobs and comparison to succeed on the same integration revision.**

## Inventory, instructions and limits

Confirmed inventory: one unmodified pinned compiler bundle and four notice
sidecars plus provenance; exact versions of `typescript`, `@types/node`,
`undici-types` in the frozen lockfile. [Inventory/notices](../THIRD_PARTY_NOTICES.md)
remain shipped with the compiler. Source/bundle parity and a clean upstream
rebuild remain unverified and are not required by the selected artifact route.
No separately copied fonts, component library, demo assets or third-party EEL2
template is used. The authored emitter/stereo DSP and generated gain example
are now present; generated JSFX does not embed the compiler bundle or its JS
runtime. This confirms the bounded shipped-material inventory, not a new
exhaustive historical legal audit or package-distribution clearance.

[README example commands](../README.md#build-the-gain-example) use the public
CLI and have been run locally. Inputs remain author-owned; the output marker
makes edits disposable. Unmarked destinations/aliases are refused. No automatic
host installation, output deployment or arbitrary existing-effect migration.
Publication safety is for ordinary local filesystems, not hostile concurrent
mutation or power-loss recovery; matrix tests do not prove every filesystem.

The [approved numeric policy](numeric-blocker.md) permits native EEL2 underflow,
including tiny normals/intermediates, and requires plain-decimal executable
numbers. Exact comparisons operate on represented values, finite/overflow/
division guards remain, and author DSP is not rewritten. No gradual-underflow
blocker, universal cutoff, software floats or Node/host tiny-branch parity.
**All real-host categories remain UNRUN** per the separate protocol. No audio/UI,
portability, latency, CPU/speedup or release-ready claim follows from local tests
or a future passing compiler matrix alone.
